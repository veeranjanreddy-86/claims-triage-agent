## Appeal package
A medical necessity appeal should include the treating clinician's notes, the history of
conservative treatment tried and failed, relevant imaging or test results, and a letter
mapping the documentation to the payer's coverage criteria.

## Missing documentation
Without clinical documentation an appeal is unlikely to succeed. Request records from the
rendering provider first; if none exist, route to write-off review. A peer-to-peer review may
be requested when documentation arrives late in the appeal window.
