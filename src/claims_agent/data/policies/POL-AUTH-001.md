## Authorization on file but not on the claim
If an approved authorization existed before the date of service, file an appeal (or
reconsideration) citing the authorization number and approval date.

## No authorization on file
When no authorization exists, request retro-authorization if the request can be made within
the payer's retro-authorization window (default 30 days from date of service). Outside the
window, route the balance to write-off review.

## Pending or denied authorization
A pending request should be followed up and expedited with the payer. A denied authorization
can be appealed when clinical documentation supports medical necessity.
